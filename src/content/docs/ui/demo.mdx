The native-first items in the registry are markup plus CSS on platform elements.
Every example below uses the same tokens and component CSS that the registry
ships, so what you see here is what you get after
`npx shadcn@latest add @ndigo/<item>`.

  Behaviour primitives (dialog, menu, select, combobox, drawer, tabs, accordion,
  popover, tooltip, slider, switch, scroll-area, navigation-menu, tags-input,
  file-upload, date-picker, command, data-table, app-shell, sidebar, code-block,

  and run the
  <a href="https://github.com/ndigo/ndigo/tree/main/apps/20-ndigo-ui-lab">UI lab</a>
  to see them live.
</Aside>
