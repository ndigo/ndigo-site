## What is Ndigo?

Ndigo gives TypeScript applications the structure of a server framework and the reach of the web.
Views, HTTP, ORM, auth, and telemetry are adopted only when needed — you pay for what you use.

<CardGrid stagger>
	<Card title="One context everywhere" icon="puzzle">
		A single `ApplicationContext` powers dependency injection in both Node and the
		browser. No separate client/server mental models.
	</Card>
	<Card title="Views as web components" icon="seti:html">
		Views render to custom elements. Server-rendered islands hydrate in place.
		Framework-agnostic output — works with React, Vue, Svelte, or plain HTML.
	</Card>
	<Card title="Adopt incrementally" icon="rocket">
		Start with routing and context. Add ORM, auth, caching, jobs, or telemetry
		only when your app needs them.
	</Card>
	<Card title="TypeScript first" icon="seti:typescript">
		TC39 decorators, strict types, ESM-only. Built for Node ≥ 24.
	</Card>
</CardGrid>
